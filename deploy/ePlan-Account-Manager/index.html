Bulk Add Account to Projects

City of Pompano Beach · Development Services · Staff tool

1Choose projects

Pick the projects to grant access to, either by pasting project numbers or by copying the project list from another existing account.

Works with BP, PZ, CE, and FP project numbers - type the full number for PZ/CE. Short forms like "24-9012" are only expanded automatically for BP, FP, and CR.

Projects selected 0

2Account to add

Choose an existing ProjectDox account, or enter details for a new one. New accounts are created automatically the first time they're added to a project.

3Access level

The project group to add this account to on every selected project. Only these two are available through this tool.

4Preview & apply

Check what will happen before making any changes. Nothing is added until you click Apply.

1Account to remove

Search for the existing account to remove access from. Only existing accounts can be looked up here.

2Choose projects to remove access from

Pick from this account's current Applicant / View Only Public access, or paste specific project numbers.

Select an account above to see its current Applicant / View Only Public access.

Works with BP, PZ, CE, and FP project numbers - type the full number for PZ/CE. Short forms like "24-9012" are only expanded automatically for BP, FP, and CR.

Projects selected 0

3Preview & remove

Check what will happen before making any changes. Only the account's Applicant / View Only Public access on the selected projects is affected - it keeps any access to other projects, and any other group memberships. Nothing is removed until you click Remove access.

Activity log

Every sign-in and every add/remove outcome, most recent first. Visible to anyone who can sign into this tool.

Every change made through this tool is logged with your staff account, the target account, project, and access level.
